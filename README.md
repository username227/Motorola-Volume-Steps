# Motorola-Volume-Steps
Magisk module to increase media volume steps from 15 to 25

Other volume step changers have broken motorola phones. I discovered that if you try to increase the volume steps to 30 or more, then you'll get breakage, causing the audio to disappear whenever volume is raised over 15. So I created this module to change it to 25 steps from the default 15. This has been tested on Moto G84 running Lineage 23, but I believe that it will work for other Motorola phones and software, including stock, where the other existing magisk modules increase it too much to work.

Feedback and issues always welcome.
